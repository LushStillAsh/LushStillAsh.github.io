17)with

with 关键字为我们提供了一种优雅的方式来处理文件操作、数据库连接等需要明确释放资源的场景。

优势

  1. 自动资源释放：确保资源在使用后被正确关闭

  2. 代码简洁：减少样板代码

  3. 异常安全：即使在代码块中发生异常，资源也会被正确释放

  4. 可读性强：明确标识资源的作用域

with 关键字，声明一个“上下文管理”代码块
expression 任意表达式，求值后必须是一个上下文管理器对象（实现了 __enter__ 和 __exit__）
[as variable] 可选部分：把 __enter__() 的返回值绑定到变量 variable；[] 是语法书里的“可选”标记，不是真让你输入方括号

参数

参数类型 定义写法 调用示例 必须传？ 关键规则
必需参数 def f(a, b): f(1, 2) ✅ 按顺序传，个数必须匹配
关键字参数（调用方式） 同上 def f(a, b): f(b=2, a=1) ✅ 按名字传，顺序无关；必须写在位置参数之后；名字要匹配
默认参数 def f(a, b=2): f(1)、f(1, b=3) ❌ 不传用默认；必须放在必需参数后；默认值只在定义时求值一次
可变位置参数 *args def f(*args): f(1, 2, 3) ❌ 多余的位置参数收进元组
可变关键字参数 **kwargs def f(**kwargs): f(x=1, y=2) ❌ 多余的关键字参数收进字典

19） lambda（匿名函数）

lambda 函数通常与内置函数如 map()、filter() 和 reduce() 一起使用，以便在集合上执行操作

  1. lambda x: x ** 2：一个匿名函数，接收 x，返回 x 的平方
  2. map(函数, 可迭代对象)：把函数依次作用到 numbers 的每个元素上
  3. map 返回的不是列表，而是一个惰性的 map 对象（迭代器）
  4. 外层的 list(...) 把 map 对象“消费”掉，转成列表
  • map：转换——每个元素都变一下，数量不变；
  • filter：筛选——只留下符合条件的，数量变少；
  • reduce：归约——把一堆元素合并成一个结果。

20）装饰器

装饰器（decorator）是 Python 中的一种高级功能，用于在不修改原函数代码的前提下，动态扩展函数或类的功能。

本质上，装饰器是一个函数：它接收一个函数作为参数，并返回一个新的函数（通常是对原函数的增强版本）

装饰器的核心思想是：用一个函数”包装”另一个函数

例：

行 代码 作用 关键点
1 def decorator_function(original_function): 装饰器入口 收到的是函数对象，不是调用结果
2 def wrapper(*args, **kwargs): 造「替身」函数 *args 打包元组、**kwargs 打包字典；闭包记住原函数
3 print("执行前") 原函数前的附加动作 调用时才执行
4 result = original_function(*args, **kwargs) 真正调用原函数 参数解包；缺这行原函数永不执行
5 print("执行后") 原函数后的附加动作 原函数抛异常时会被跳过
6 return result 交出返回值 不写则永远返回 None
7 return wrapper 交出替身函数对象 不能加括号，加了会立刻执行
8 @decorator_function 语法糖：换名字 等价于一次赋值（见下）
9 def target_function(): 被装饰的原函数 定义 ≠ 执行
10 print("原函数执行") 原函数体 被 wrapper 调用时才打印
11 target_function() 顶格调用，触发一切 不写 = 0 输出

21）数据结构

1.列表

方法 描述
list.append(x) 把一个元素添加到列表的结尾，相当于 a[len(a):] = [x]。
list.extend(L) 通过添加指定列表的所有元素来扩充列表，相当于 a[len(a):] = L。
list.insert(i, x) 在指定位置插入一个元素。第一个参数是准备插入到其前面的那个元素的索引，例如 a.insert(0, x) 会插入到整个列表之前，而 a.insert(len(a), x) 相当于 a.append(x) 。
list.remove(x) 删除列表中值为 x 的第一个元素。如果没有这样的元素，就会返回一个错误。
list.pop([i]) 从列表的指定位置移除元素，并将其返回。如果没有指定索引，a.pop()返回最后一个元素。元素随即从列表中被移除。（方法中 i 两边的方括号表示这个参数是可选的，而不是要求你输入一对方括号，你会经常在 Python 库参考手册中遇到这样的标记。）
list.clear() 移除列表中的所有项，等于del a[:]。
list.index(x) 返回列表中第一个值为 x 的元素的索引。如果没有匹配的元素就会返回一个错误。
list.count(x) 返回 x 在列表中出现的次数。
list.sort() 对列表中的元素进行排序。
list.reverse() 倒排列表中的元素。
list.copy() 返回列表的浅复制，等于a[:]。
